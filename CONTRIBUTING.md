# Katkı

Kaynağı nasıl indireceğini [INDIRME.md](INDIRME.md) anlatır. Bu sayfa yerel çalıştırma ve gönderim içindir.

```bash
git clone https://github.com/kdorukdemirtas-star/Akilli-Orman-Gozlemcisi-Software.git
cd Akilli-Orman-Gozlemcisi-Software
cp .env.example .env.local
npm install
npm test
npm run dev
```

`.env`, `.env.local`, Pi şifresi ve ağırlık dosyaları commit edilmez. PWA metninde kip adları Hızlı cevaplar / Orta cevaplar / Derin cevaplar kalır; model adı yazılmaz. Alarm kuralı AND'dir: 100 °C ve alev.

Asistan vekili: `pi/README.md`.
